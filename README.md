# 🌿 ***PlantDex*** 🍃
Hybrid 3DS Field Guide &amp; ML Plant Identifier Prototype
## 🌱 **ABOUT**
PlantDex is a hybrid prototype tool designed to explore a more sustainable and ecological approach to technology, blending homebrew software, open-source machine learning (ML), and a nostalgic field guide experience build around the 3DS that is inspired by the Pokédex and a desire to repurpose old technology.<br/><br/>
It transforms the 3DS into a field observational tool, capturing plant photos and passing them to a Python backend that communicates with the PlantNet Identification API which then returns identification candidates. The 3DS would then display possible species, confidence values, common names, reference images, and notes about the ecology and usages. It would then allow you to store your field discoveries in a personal plant library, thus creating a living, growing record of your local ecosystem.<br/>
> [!NOTE]
> Plant identification is powered by PlantNet (https://plantnet.org)  
> Data and images returned from the API follow the license terms of their respective contributors

This project is an exploration in the interconnectedness between technology and nature. I am inspired by land-based learning, community efforts towards accessible and open ecological knowledge databases, as well as off-grid and low-power computing tools.
